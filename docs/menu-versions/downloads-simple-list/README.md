# Downloads Simple list

Preserved menu version for developer handoff.

- Version name: `Downloads v1 - Simple list`
- Review folder: `docs/menu-versions/downloads-simple-list/`
- Agent handoff: `docs/menu-versions/downloads-simple-list/AGENTS.md`

The supplied reference is `reference.png`.

External issue and design links are intentionally omitted from this folder. Share those separately when handing this slice to another reviewer or engineer.

The menu contains a Downloads heading, a Product downloads group, five product links in this order, a favorite star per product, and Browse all Downloads:

1. Red Hat Enterprise Linux — Installation media, images, and architecture choices
2. Red Hat OpenShift — Clients and tools for your OpenShift environment
3. Red Hat Ansible Automation Platform — Installation bundles and automation software
4. Application Services — Application runtimes, releases, and updates
5. Red Hat Satellite — Satellite installation and management software

The reference also preserves the surrounding Platforms/Services selector and keyboard guidance. The global search shell, other console content, and destination pages can evolve independently. Changes to this menu version require a separate review; do not overwrite it while updating upstream search.

Review checklist: Step 1 (global search location) completed by the user. Next check: open global search, choose Downloads in Services, and compare this menu to the reference. This records the named version, not acceptance of all batch 1 changes.

This folder intentionally isolates only the `Downloads v1 - Simple list` menu behavior and its traceable review assets. Public Downloads handoff notes in this folder should not cross-reference unrelated prototype explorations or non-Downloads work.
